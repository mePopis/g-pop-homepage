# G Pop | Web Development Portfolio

A personal portfolio showcasing my web development projects
and the skills I’m developing with HTML, CSS and JavaScript.

## Live website

[Visit the G Pop portfolio](https://mepopis.github.io/g-pop-homepage/)

## Features

- Responsive layout for desktop and mobile screens
- Skills section covering the technologies I’m learning
- Project cards with screenshots, live websites and source code links
- About section and a link to my GitHub profile
- Keyboard-accessible navigation and a skip-to-content link

## Built with

- Git and GitHub for version control
- GitHub Pages for hosting
